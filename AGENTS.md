# BUHARIY TECH

Work from this repository root. Do not edit the unrelated PulmatikAi project.

Read docs/architecture.md and packages/contracts/src/index.ts before cross-application contract changes. Shared Zod contracts enforce input validation; keep public and private response boundaries explicit.

The graph is in graphify-out/graph.json. Use `graphify query`, `graphify path` or `graphify explain` before broad codebase searches. After code changes run `graphify update .`.

Do not commit .env, generated credentials, .local or private client data. Never replace a real logo with an invented mark. Label demo portfolio records Concept Project. Never invent employees, testimonials or client metrics.

Preserve transactional image limits, one-cover behavior, immutable consent policy versions, role guards and refresh-session revocation. Apply relevant tests after changes; integration tests require local PostgreSQL/MinIO. Production deployments are separate from local previews.
